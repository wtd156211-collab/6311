# 词形归一与词干化（从 0 实现）

起始环境只有本说明、`samples/**` 与 `.gitignore`：词表装载、规则与例外、归并与反查索引、查询召回、
命令行和一页自包含的 Canvas 连线图都从零写。交付 `stem.py`（入口）、`data/rules.tsv`、
`data/exceptions.tsv`、`web/index.html`。Python 3.13 标准库 + 浏览器原生能力，不引第三方、不加构建、
不联网；`samples/**` 只读，运行期只写 `var/` 与 `--out`。

## 一、范围

做：整词归一（后缀、复数、时态、比较级、数量词）→ 反查索引（归一形式对应哪些原词）→ 按查询用例
召回同族词形 → 页面。

不做：拼写纠错、同义词、词性标注；派生词不合并（`submit`/`submission`、`work`/`worker`、
`teach`/`teacher` 分属不同族）；中文分词与中文词形、其他语种、Unicode 归一、全半角折叠、大小写保留
（统一小写）；停用词、相关性排序（召回按码点升序）；联网、多线程、增量索引、数据库。

## 二、口径与公式

词形 = 预处理后的串；预处理 = 去首尾空白 + 转小写；只允许 `a`–`z`，长度 1–64。

`f(w)`：① 命中例外表 → 取表里的归一形式；② 否则按规则表逐条试（后缀长度降序、同长按序号升序），
第一条条件全满足的规则生效；③ 都不命中 → `f(w) = w`。

规则表六列 `序号 / 后缀 / 替换 / 最小词干 / 要求 / 修补`，默认内容随产物提供：

| 序号 | 后缀 | 替换 | 最小词干 | 要求 | 修补 |
| --- | --- | --- | --- | --- | --- |
| 1 | `iest` | `y` | 2 | 形容词 | - |
| 2 | `ies` | `y` | 2 | - | - |
| 3 | `ied` | `y` | 2 | - | - |
| 4 | `ier` | `y` | 2 | 形容词 | - |
| 5 | `ing` | 删除 | 3 | - | 短化 |
| 6 | `est` | 删除 | 3 | 形容词 | 短化 |
| 7 | `es` | 删除 | 2 | 咝音 | - |
| 8 | `ed` | 删除 | 3 | - | 短化 |
| 9 | `er` | 删除 | 3 | 形容词 | 短化 |
| 10 | `s` | 删除 | 2 | - | - |

最小词干 = 去掉后缀后剩余长度下限，不达标就跳过（`is`、`this` 不会被剥）。要求「咝音」= 词干以
`x`/`z`/`ch`/`sh`/`ss` 结尾才生效（`boxes`、`passes` 走这条；`houses` 走第 10 条只掉一个 `s`）。
要求「形容词」= 修补后的候选要在词表里、且词性含 `adj` 或 `adv`，否则换下一条（`worker`、`carrier`
不剥，`honest` 不动）。

短化只对标记「短化」的规则执行，候选 `s` = 词干接替换串之后：① `s` 末尾两个相同辅音、该字母不是
`l`/`s`/`z`、且 `s` 长度 ≥ 4 → 去掉末位（`hopp`→`hop`；`add` 不动）；② 否则 `s + "e"`
在词表里 → 取 `s + "e"`（`hop`→`hope`、`larg`→`large`）；③ 否则 `s` 只含一个元音、末三字符是
「辅音+元音+辅音」、末位不是 `w`/`x`/`y` → 末尾补 `e`；④ 否则原样（`work`、`open` 不动）。

反查：`index(s) = { w ∈ 词表 | f(w) = s }`，族内按码点升序。召回：查询词先预处理再归一，取
`index(f(查询词))`；查询词可在词表外，族成员来自词表，无成员输出空串。

## 三、状态机与数据结构

流水线：载入并校验（词表、规则、例外）→ 逐词归一 → 建反查索引 → 逐条召回 → 渲染页面。内存结构：
词表索引「词形 → (词性集合, 归一形式)」、有序规则表、例外表「词形 → 归一形式」、反查索引
「归一形式 → 成员」。任一非法输入都在产出结果前失败，退出码 1。

## 四、输入输出与文件格式

数据文件一律 UTF-8 无 BOM、LF、末行有换行；`#` 与空行忽略；字段 TAB 分隔。

### 4.1 词表与标注 `samples/words/*.tsv`

词表 `词形 <TAB> 词性 [<TAB> 备注]`，词性取 `n`/`v`/`adj`/`adv`/`quant`/`other`，可并列（`n,v`）；
`families.tsv` 是人工标注，列 `词形 / 族标签 / 依据`，族标签即归一形式。重复词形按首次计，空词表合法。

### 4.2 规则表 `data/rules.tsv` 与例外表 `data/exceptions.tsv`

规则表六列同上表，替换写 `-` 表示删除后缀；例外表三列 `词形 <TAB> 归一形式 <TAB> 类型`，类型取
`不规则`/`保护`/`歧义`/`数量词`，同一词形两个归一形式即输入错误。例外表至少覆盖样例里的全部不规则
形、保护词（`news`、`series`、`bus` 这类不能被剥的整词）、歧义词形（`leaves`）与数量词。

### 4.3 查询清单 `samples/cases/query_cases.txt`

一行一个查询词，用同一套预处理与校验。

### 4.4 命令

```
python3 stem.py run    --words <词表> [--out <目录>=var]
python3 stem.py recall --words <词表> --queries <查询清单>
python3 stem.py web    --words <词表> [--out web/index.html]
```

- `run` 写 `<目录>/stem.tsv`（`词形 <TAB> 归一形式`，行序同词表）与 `<目录>/index.tsv`
  （`归一形式 <TAB> 成员,成员,…`，族内码点升序，行序按归一形式码点升序），stdout 一行
  `words=<词形数> families=<族数>`。
- `recall` 逐行打印 `预处理后的查询词 <TAB> 成员,成员,…`（无命中为空串），行序同查询清单。
- `web` 生成单文件页面：数据内联、无外链、双击即开；左列词形、右列归一形式，连线表示
  归属；点击右侧节点高亮族成员；顶部给出词形数、族数与折叠率。
- 退出码：0 成功；1 词表/规则/例外/查询非法（stderr 一行 `error: …`，含文件与行号，stdout 为空）；
  2 用法错误。

## 五、性能与验收口径

单进程单线程、Python 3.13。预算：`samples/words/scale.tsv`（1 万词形）装载 + 归一 + 建索引
≤ 1.5 s 墙钟（不含解释器启动，`time.perf_counter`），峰值内存 ≤ 256 MiB（`tracemalloc` 扣基线）；
同表 1000 条召回 ≤ 0.5 s；页面打开到可交互 ≤ 2 s。

1. 逐行核对（期望文件都在 `samples/cases/` 下）：`run` 的 `stem.tsv`、`index.tsv` 分别与
   `stem_expected.tsv`、`index_expected.tsv` 逐字节一致；stdout 与 `run_summary.expected.txt`
   一致；`samples/words/scale.tsv` 的 `stem.tsv` 与 `scale_expected.tsv` 一致。
2. 召回：`recall` 输出与 `query_expected.tsv` 逐字节一致。
3. 过度归并：`overmerge_guard.tsv` 每行两词归一结果必须不同（0 对违反）；同分布的扩大标注集上被
   错误合并的对数 ≤ 2。
4. 漏归并：`samples/words/families.tsv` 同族词形必须同一形式（0 处不一致）。
5. 确定性：同一命令连跑两遍、`PYTHONHASHSEED=0/1/2` 下 stdout 与 `var/**`、`web/index.html`
   逐字节相同；不写时间戳与随机数。
6. `samples/**` 只读；除 `var/` 与 `--out` 外不落盘。

## 六、样例说明

| 素材 | 规模 | 看点 |
| --- | --- | --- |
| `samples/words/vocab.tsv` 配 `families.tsv` | 372 词形 / 125 族 | 词表与人工标注（族标签 + 依据）：复数、时态、比较级、数量词、不规则形与保护词 |
| `samples/cases/stem_expected.tsv` 配 `index_expected.tsv` | 372 行 / 125 行 | 逐词期望输出与反查期望，含 `be`、`good`、`far`、`many` 等多词形族 |
| `samples/cases/query_cases.txt` 配 `query_expected.tsv` | 30 条 | 词根与词形互查、大小写混写、派生词不串族、`news` 不带出 `new`、词表外空 |
| `samples/cases/overmerge_guard.tsv` | 22 对 | 必须分开的（词形、词形、理由）三列：保护词、派生词、双写与补 `e`、`-er`/`-est` 门槛 |
| `samples/words/scale.tsv` 配 `scale_expected.tsv` | 1 万词形 | 九类形态的机械样例，核对规模与耗时预算 |

覆盖：复数与时态（含保护词、双写与补 `e`）、比较级、不规则形、数量词、派生词不合并；
`samples/notes.md` 只作背景，不作为口径。
